## Français

Ce dépôt n'est plus maintenu ici.

**AntibiAutomatismes est désormais hébergé sur la Forge des Communs Numériques Éducatifs :**

### → https://forge.apps.education.fr/philipperackette/AntibiAutomatismes

Vous y trouverez la version **2.0** et toutes les versions suivantes : le code, les
83 générateurs, les presets, le catalogue complet et la suite de tests.

```bash
git clone https://forge.apps.education.fr/philipperackette/AntibiAutomatismes.git
```

Signalements et suggestions : passer par les
[tickets de la Forge](https://forge.apps.education.fr/philipperackette/AntibiAutomatismes/-/issues).

### Pourquoi ?

La Forge est le service d'hébergement de code du ministère de l'Éducation nationale,
dédié aux communs numériques éducatifs. C'est le lieu naturel d'un outil destiné aux
enseignants.

### En bref

Générateur de sujets et d'exercices de mathématiques inspiré de la méthode **Antibi**,
conçu pour produire rapidement des feuilles d'entraînement aux automatismes au collège et
au lycée, au format LaTeX/PDF.

## English

This repository is no longer maintained here.

**AntibiAutomatismes has moved to the Forge des Communs Numériques Éducatifs, the French
Ministry of Education's code hosting service:**

### → https://forge.apps.education.fr/philipperackette/AntibiAutomatismes

Version **2.0** and all later releases live there: source code, the 83 exercise
generators, presets, the full catalogue and the test suite.

```bash
git clone https://forge.apps.education.fr/philipperackette/AntibiAutomatismes.git
```

Issues and suggestions: please use the
[Forge issue tracker](https://forge.apps.education.fr/philipperackette/AntibiAutomatismes/-/issues).

### In short

A mathematics worksheet generator inspired by the **Antibi** approach, designed to quickly
produce LaTeX/PDF practice sheets focused on procedural fluency at secondary level.
